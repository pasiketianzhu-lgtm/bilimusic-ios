# BiliMusic iOS 一期整合与验证

本版整合确认方案中的本地音乐库功能；双设备云同步仅预留数据标识，不开放入口。

## 实现范围
- 四个主入口、我喜欢和爱心按钮、个人歌单预览、按收听时间排序的最近播放。
- 复用原有歌单创建、编辑、封面、置顶、拖动和批量操作；新增独立收藏夹分页导入、排除选择、新建/已有目标、取消、错误清单和重试。
- 多 P 页面沿用独立分 P 选择与加入歌单；不拆分连续长合集。
- 本地歌曲/歌单搜索与 B 站搜索入口；原始标题和封面。
- 正向/倒序、随机与循环；随机默认排除超过 1800 秒内容、不连续抽中当前项；可为当前条目设置随机参与和记住位置。
- 队列持久化、每条长内容续播、下一首插播、原有队列拖动；保留已有超过两小时音轨的本地 HLS 加速方案。
- iPhone 播放页、iPad 横屏队列/封面控制/歌词三栏、响应式封面、系统锁屏控制、耳机断开暂停、中断恢复、定时与当前条目结束停止。
- 自动/手动歌词匹配、LRC 文件导入、显式使用视频字幕、时间偏移；无歌词不影响播放。
- 单首与整单下载、长内容确认、空间估算、下载音质、并发调度、暂停/继续/取消/重试、进度和大小、已下载入口、歌单完成计数与总占用。
- 本地库离线查询、已下载优先播放；凭证迁移至系统钥匙串；系统歌单标识与未来同步 ID 的 SQLite 迁移。

## 本地验证
- pnpm type-check：通过。
- pnpm lint：通过，已等待进程结束确认 exit 0。
- Node 测试：导航配置、首页排序、歌单规则、分页导入、空间估算、凭证分离、字幕时间转换，共 7 项通过。
- Python SQLite：从 0000 到 0023 全量迁移通过，验证旧记录回填、系统歌单唯一约束与改名稳定性。
- iOS JavaScript 导出：通过（单进程、项目内临时目录；默认 Windows 缓存曾出现 EPERM，重试后导出成功）。

## 独立审查与修复
独立审查发现并修复：周期全局续播保存、落盘失败后下载任务释放、横屏歌词页返回、随机计数重置、暂停后异步加载自动启动、暂停任务恢复绕过并发限制、插播后索引漂移。

## 尚需最终环境验证
Swift 队列真实源码的 smoke tests 已接入最终 EAS macOS 构建。Windows 不具备 Xcode；Apple 框架编译、iPad/iPhone 真机布局、锁屏/耳机行为和账号相关在线接口仍须由最终构建与一次设备验收确认。
